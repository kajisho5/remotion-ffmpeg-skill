# remotion-ffmpeg-skill brand assets

The icon is a Liquid Glass app icon made with [fresnel](https://github.com/kajisho5/fresnel): measured audio levels inside the corner marks of a video frame — the skill measures the footage, then draws inside the frame. The wordmark is set in Inter SemiBold (SIL Open Font License 1.1), outlined.

| File | Use |
|---|---|
| `png/icon-512.png`, `png/icon-dark-512.png` | icon, Default / Dark appearance, masked |
| `png/icon-fullbleed-1024.png`, `png/icon-dark-fullbleed-1024.png` | unmasked, opaque squares |
| `logo/logo-dark.svg`, `logo/logo-light.svg` | horizontal lockup for dark / light backgrounds |
| `logo/wordmark-white.svg`, `logo/wordmark-black.svg` | wordmark only |

The editable icon bundle, its layer sources, the wordmark script, the GitHub social preview and the README's demo images live on the [`media` branch](https://github.com/kajisho5/remotion-ffmpeg-skill/tree/media), so the skill itself ships only text and the icons it needs.

Write the name in lowercase. The icon does not use Remotion's or FFmpeg's marks; this project is not affiliated with either.
